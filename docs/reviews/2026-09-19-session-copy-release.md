# Sessions: ปรับข้อความและคำแนะนำ — 19 กันยายน 2026

## สรุป

รอบนี้แยกจากงานค้างอื่นตามคำอนุมัติ: ปรับเฉพาะข้อความในประวัติการใช้งาน
และคำแนะนำในรายงาน ไม่เปลี่ยนสูตร Sleep Score / Recovery Score, Sleep State,
เกณฑ์ Baseline, Sensor หรือคำสั่งอุปกรณ์

## ข้อความที่ปรับ

| เดิม | ใหม่ |
| --- | --- |
| อะไรช่วยให้พักได้ดี | รายละเอียดคะแนน |
| บรรยากาศที่ช่วยพัก | สภาพแวดล้อม |
| สิ่งที่ทำได้ดี / สิ่งที่ลองปรับได้ | จุดเด่นของการพัก / ข้อสังเกต |
| เริ่มเห็นรูปแบบของคุณ | ใช้ข้อมูลการพัก … ครั้งประกอบการประเมิน |
| กำลังเรียบเรียงรายละเอียดการพักของคุณ | กำลังโหลดผลการพัก |

คำแนะนำแสดงหนึ่งข้อ พร้อมช่วงเวลาที่ใช้ และเปิดอ่านเหตุผลเพิ่มเติมได้
ลดคำซ้ำ เช่น “ก่อนพักครั้งถัดไป” ในเนื้อความที่มีป้ายช่วงเวลาอยู่แล้ว
คำแนะนำทั่วไปต้องระบุว่าเป็นคำแนะนำทั่วไป ไม่กล่าวอ้างว่าเป็นผลเฉพาะบุคคล
หากยังไม่มีหลักฐานรองรับ ไม่อนุมานความสดชื่นหรือความพร้อมจากคะแนน

## การแสดงรายงานเดิม

หน้า Sessions ใช้ `/api/history/{username}/{session_id}` ซึ่งเคยคืนข้อความ
ที่บันทึกพร้อมรายงานเก่า เพิ่ม `sessions/report_copy.py` ให้สร้างคำอธิบาย
ปัจจุบันด้วย Result Contract เดียวกับ Usage API เมื่ออ่านรายงาน
แทนเฉพาะ `restore_summary` ใน response โดยไม่บันทึกทับฐานข้อมูล

คะแนน คุณภาพข้อมูล รายการสิ่งแวดล้อม และลำดับการนอนในรายงานยังคงเดิม
ไม่มีการ rerun สูตรคะแนนหรือแก้ Raw file ใน release นี้
ฟังก์ชันสรุปผลร่วมทำให้หน้าจบการพักใช้ข้อความเดียวกับหน้า Sessions ด้วย

## ปรับสัดส่วนตัวอักษรหลังรีวิวหน้าจอ

พบข้อความรองเดิม 10–12 px เล็กเมื่อเทียบกับวงคะแนน จึงกำหนดขนาดร่วมใน
`static/styles/result-summary.css`: เนื้อหา 16 px, ป้าย 14 px, หมายเหตุ 13 px,
หัวข้อส่วน 18 px และหัวข้อผล 24–28 px พร้อมระยะบรรทัด 1.5–1.65
วงคะแนนลดตามพื้นที่จาก 136 เป็น 112 หรือ 96 px โดยไม่เปลี่ยนค่าที่แสดง

ใช้ container query ตามความกว้างการ์ดจริง แทนการอ้างอิงขนาดหน้าต่างเพียงอย่างเดียว
เพื่อรองรับหน้า Sessions ที่มีแผงด้านข้างและหน้าจบการพักร่วมกัน
ตรวจ Nap และ Overnight ที่ 320, 390, 768 และ 1280 px: ไม่มีการล้นแนวนอน
หรือข้อความหลุดกรอบ และตรวจด้วยภาพบนหน้าต่างเดิม 609 px ด้วย
รอบนี้เปลี่ยนเฉพาะ CSS และเลขรุ่นไฟล์เพื่อให้ browser โหลดรูปแบบใหม่
ไม่เปลี่ยนคำแนะนำ คะแนน หรือ API
